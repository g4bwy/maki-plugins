# Table of Contents Plugin

A Wikipedia-style contents pane for the transcript. A left split lists every
user turn; fold one open to see its thinking and reply blocks. Selecting any
row scrolls the chat to that turn.

Maki's own transcript has no sidebar. To find an earlier exchange you scroll or
`/search`. This plugin gives the session an outline you can read and jump
around.

## Requirements

The plugin calls APIs that a stock maki build does not yet expose:

- `maki.ui.transcript_outline()` — the jumpable blocks of the transcript, as
  the chat itself lists them, with first-line previews.
- `maki.ui.scroll_to_block(position)` — scroll the focused chat to the
  position-th entry of `maki.ui.transcript_outline()`.
- window click events — `win:recv` must yield `{ type = "click", row, col }`.

All are maki's plugin Lua API, documented under `maki.ui` and `Win:recv` in
the lua-api docs (generated by `just gen-docs` in a maki checkout). Without
them the pane would open but never jump, so the plugin checks at open time and
flashes `this maki build lacks the transcript outline api` instead.

## Installation

1. Copy the module into maki's config dir:

   ```sh
   mkdir -p ~/.config/maki/lua
   cp init.lua ~/.config/maki/lua/toc.lua
   ```

2. Load it from `~/.config/maki/init.lua`:

   ```lua
   require("toc")
   ```

3. Restart maki, or run `/reload`.

The plugin uses no gated APIs, so it needs nothing in `plugin.toml`.

## Usage

Toggle the pane with `/toc` or `Alt+t`. Open it once; it lists the turns in the
current session and follows the transcript as it grows.

| Action | Mouse | Keyboard |
|--------|-------|----------|
| Toggle the pane | — | `Alt+t`, or `/toc` |
| Move the selection | — | `Alt+j` / `Alt+k`, or arrows |
| Fold / unfold a turn | click `▸` / `▾` | `Alt+o` |
| Jump to a turn | click its text | `Alt+Enter` |
| Jump to a thinking/reply block | click the sub-item | select it, `Alt+Enter` |

Clicking the number or marker column at the left of a turn row folds that
turn; clicking anywhere else on the row jumps to it. Sub-items (`thinking 1`,
`reply 1`, ...) jump to that exact block in the transcript, so a long turn can
be entered at its answer instead of at its question. A turn with nothing under
it shows no marker.

Keys reach the pane because it opens as an unfocused split that claims just
these bindings (the window `keys` option), so `Alt+t` and the rest work while
your typed message still goes to the chat. Terminals that send plain characters
for `Alt` may need the terminal set to "Meta sends Escape"; without it, use the
mouse or `/toc`.

## How it works

The tree comes from `maki.ui.transcript_outline()`, which returns exactly the
blocks the chat will jump to — turns, thinking and reply — in display order,
each with a first-line preview. The plugin only groups: every `turn` entry
opens a row, the `thinking` and `reply` entries that follow become its
children, and each row carries its entry's position in the outline, the one
address `maki.ui.scroll_to_block(position)` takes. Which messages count as
visible turns is the host's decision alone, so the pane and the chat cannot
disagree about what a position means.

Rows are numbered in transcript order. Tool calls stay out of the outline, to
keep it short; folding a turn shows its thinking and reply text only.

The pane rebuilds on `TurnStart`, `TurnEnd`, and `ToolDone`, and resets on
`/new`, session switch, and compaction, when turn numbers move.

## Limitations

- **Main transcript only.** While you are viewing a sub-agent's chat, jumping
  flashes a note instead of scrolling the wrong transcript. The outline tracks
  the main session.
- **Sub-items appear at turn end.** Maki publishes thinking and reply blocks to
  the shared transcript when a turn completes, so a running turn lists its
  header first and gains children once it finishes.
- **Scroll, not select.** Jumping moves the chat viewport; it does not place the
  cursor in the input or rewind context. Everything after the chosen turn stays
  in view below it.
